Try It Yourself

Generate your own demo reports in 60 seconds:

# Download and run the demo
curl -fsSL https://raw.githubusercontent.com/Matt-C-G/QuietPatch/main/scripts/qp-report.py -o qp-report
chmod +x qp-report

# Generate Executive Report
./qp-report exec --scan data/scan.json --kpi data/kpi.json --out exec.html

# Generate Technical Report  
./qp-report tech --scan data/scan.json --out tech.html

# Open results
open exec.html tech.html
